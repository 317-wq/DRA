## 1. 本版范围

**包含什么**：

1. **`dra ui`**：只绑 `127.0.0.1`，自动开浏览器；端口被占用时自动往后找。
2. **实时事件流**：页面通过 SSE 订阅 `runs/<id>/trace.jsonl`，刷新页面甚至重启进程都能回放。
3. **三块结果视图**：报告（Markdown 服务端渲染）、来源（编号 / 域名 / `link_status`）、轨迹（事件表）。
4. **历史**：左侧列出历史 run，点开即可回看报告、来源与轨迹。
5. **单任务**：本地单用户，一次只跑一个研究；重复发起返回 409。

**不包含什么**：

- 知识库、追问树（→ 0.4 / 0.5）
- 多用户、登录、远程访问（本地工具，不做）
- 前端构建链（原生 HTML/CSS/JS；不引 React/Vite）
- 取消正在运行的任务（下一版再加）

## 2. 本版用户路径

> `dra ui`
> → 浏览器打开 `http://127.0.0.1:8765`
> → 输入主题、设定来源上限 → 开始研究
> → 左侧实时看到拆题 / 检索 / 阅读 / 分析 / 写作
> → 结束后右侧自动出现报告，可切来源与轨迹
> → 刷新页面或点历史，仍能回放同一次研究

## 3. 相对基线的增量

- 架构 / 模块改动：新增 `dra/jobs.py`（后台任务与事件读取）、`dra/web/`（FastAPI 应用与静态页）。
- 技术选型改动：Web 层落地为 **FastAPI + uvicorn + SSE**；Markdown 用已存在的 `markdown-it-py` 渲染，不新增前端依赖。
- 接口改动：
  - 新增命令 `dra ui [--port] [--no-browser]`
  - 新增 HTTP 接口：`/`、`/api/runs`（GET/POST）、`/api/runs/{id}`、`/report`、`/sources`、`/trace`、`/events`
  - `ResearchAgent.run()` 新增可选 `run` 参数，允许外部预创建 run（UI 需要先拿到 id）
- 其他：版本 0.3.0。

## 6. 本版风险与待办

- **无鉴权**：只监听回环地址，本机其他进程仍可访问；1.0 如需多用户再加 token。
- **单任务**：`BusyError` 直接拒绝；后续可做队列。
- **SSE 用文件轮询**：延迟约 0.35s，够用；将来事件多可换进程内总线。
- **取消/中断**：页面关闭不会停止后台研究，任务会继续跑完。
- **前端未做浏览器自动化测试**：只有 API 层测试，视觉回归靠人工。
