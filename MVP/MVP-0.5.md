# MVP-0.5 · 知识库页面与一键沉淀

> 基线：PROJECT.md v1.5
> 前置版本：MVP-0.4（知识库内核）
> 日期：2026-10-21
> 状态：**已完成**（API 与真实沉淀验证；浏览器视觉待你过一眼）
> 已同步至 PROJECT.md v1.5（知识库 HTTP 接口）

## 1. 本版范围

**包含什么**：

1. **知识库视图**：侧栏新增「知识库」，页面里能看文档列表、块数、向量化数量。
2. **一键沉淀**：报告页右上角按钮，把当前 run 的报告写进知识库；重复点击返回“已在知识库”。
3. **页面检索**：输入查询 → BM25 + 向量 + RRF，展示命中块、分数与来源文档。
4. **删除**：文档列表可直接删除（级联清理 chunks）。
5. **零搜索额度**：沉淀与检索只调用 embedding，不碰 Tavily。

**不包含什么**：

- 分类/标签、rerank、引用回链（0.6 之后）
- 自动沉淀（研究结束自动入库）——先保留手动确认
- 多知识库、共享（本地单用户）

## 2. 本版用户路径

> `dra ui` → 跑完一次研究
> → 报告页点「沉淀到知识库」
> → 切到左侧「知识库」→ 输入查询
> → 看到命中块、分数与所属报告
> → 不需要时直接删除文档

## 3. 相对基线的增量

- 架构 / 模块改动：`dra/web/server.py` 增加知识库接口；前端新增视图与沉淀按钮。
- 接口改动：
  - `GET /api/kb`：统计 + 文档列表
  - `GET /api/kb/search?q=&k=`：混合检索
  - `POST /api/kb/sink {run_id}`：沉淀报告
  - `DELETE /api/kb/{doc_id}`：删除文档
- 其他：版本 0.5.0。

## 6. 本版风险与待办

- **无分类**：文档只有标题与来源 run，文档多了不好找；0.6 可加分类/标签。
- **无 rerank**：向量阈值缺失，语义噪声靠 RRF 压制。
- **手动沉淀**：不会自动入库；如果觉得麻烦，下一版可加“研究完成后自动沉淀”开关。
- **浏览器未自动化**：只有 API 层测试。
