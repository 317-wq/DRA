# MVP-1.8 · 界面反馈修复

> 基线：PROJECT.md v1.17
> 前置版本：MVP-1.7（检索精度与左右布局）
> 日期：2026-10-21
> 状态：**已完成**（119 个离线单测；界面截图验证）

## 1. 本版修复

1. **质量空态误报**：没有开始研究时不再显示「报告已生成，可以立即评估」，
   改为「开始一次研究后，这里会显示报告质量」；失败/取消的 run 显示无报告可评估。
2. **左栏可滚动**：阶段列表 + 事件流超出高度时整栏可滚动，不再被截断。
3. **历史追问可收起**：`hidden` 被 `display:flex` 覆盖导致收不回去；补 `[hidden]` 规则，
   并把按钮文案在「▶ N 条追问 / ▼ 收起追问」之间切换。
4. **Logo 替换**：左上角换成用户提供的机器人图标（128×128 PNG，28 KB）。
5. **文档双标记**：每个文档右侧显示两个标记：
   - 格式：`MD` / `PDF` / `TXT`
   - 来源：`上传` / `研究沉淀`
   后端在列表与详情里补充 `format` 和 `origin` 字段。

## 3. 风险与待办

- Logo 为 128×128，高 DPI 下略糊；后续可换 256×256。
- 文档格式从 `source_path` 后缀推断，极少数无后缀文件会落到默认 `MD`。
- 来源目前只区分「上传 / 研究沉淀」，没有记录上传者与时间。
