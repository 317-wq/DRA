## 1. 本版范围

**包含什么**：

1. **追问树**：可以对一条追问继续追问，不再只能从主报告出发。
   - 元数据记录 `parent_run_id` 与 `parent_followup`；
   - 证据选择同时参考“父追问 + 新问题”；
   - 引用继续沿用同一批来源编号。
2. **继续研究**：在一份已完成报告上追加新问题，继承父来源、只补检索缺口，产出新版报告。
   - 子任务记录 `parent_run_id` / `mode=continue` / `continue_questions`；
   - 旧来源编号原样保留，新来源从 `max(n)+1` 开始；
   - 新版报告带父报告上下文，不重搜旧来源（URL 去重）。
3. **API**：
   - `POST /api/runs/{id}/followups` 支持 `parent_followup`；
   - `POST /api/runs/{id}/continue`，body `{questions, max_sources}`。
4. **CLI**：`dra ask --followup <id>` 对追问继续追问。

**不包含什么**：

- 前端追问树的树形展示（接口已返回父子关系）
- 继续研究的前端入口
- 继续研究的多轮链式（一次只做一层）

## 2. 用户路径

> 报告 → 追问 A → 对 A 继续追问 B（引用仍指向同一来源）
> → 报告 → 继续研究（补 1–4 个新问题）→ 新版报告，旧编号不变

## 3. 相对基线的增量

- `dra/followup.py`：父级解析支持 run/followup；元数据加父子字段。
- `dra/agent.py`：`seed_sources / seed_report / seed_questions / parent_run_id`。
- `dra/jobs.py`：`start_continue()`；worker 从父 run 装载种子。
- `dra/prompts.py`：计划与写作提示词支持父报告。
- API/CLI 对应入口。

## 6. 本版风险与待办

- **上下文变长**：继续研究会把父来源全部带入，提示词会随来源数增长；后续可只带被引用来源。
- **继承语义**：新版报告是“更新版”，不是追加章节；旧报告不会被修改。
- **追问树展示**：接口有父子字段，前端还没画树。
- **链式继续**：目前只支持一层；对继续研究的结果再继续，需要再验证编号继承。
- **来源上限**：`max_sources` 表示“新增来源数”，总来源 = 父来源 + 新增。
