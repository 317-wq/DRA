# MVP-1.5 · 研究历史页与知识库分栏

> 基线：PROJECT.md v1.14
> 前置版本：MVP-1.4.1（界面重做）
> 日期：2026-10-21
> 状态：**已完成**（111 个离线单测；界面已截图验证）

## 1. 本版范围

**包含什么**：

1. **独立「研究历史」页**：卡片式列表，显示状态、时间、来源数、字数、追问数。
2. **历史卡片操作**：查看报告 / 继续研究 / 基于此追问 / 沉淀到知识库 / 删除。
3. **追问展开**：有追问的 run 可以展开列表，点进去直接看回答。
4. **知识库左右分栏**：左侧文档列表与检索，右侧文档详情（分块全文）。
5. **文档详情接口**：`GET /api/kb/{doc_id}` 返回文档元数据与全部分块。
6. **列表增强**：`GET /api/runs` 补充 `chars` 与 `followup_count`。
7. **深链接**：`?view=history`、`?view=kb&doc=<id>`、`?run=<id>&tab=<tab>`。

**不包含什么**：

- 知识库上传任意文件（当前仍从报告沉淀）
- 分类/标签编辑（数据层没有标签字段）
- 参考图里的演示控制（播放流程/模拟失败）
- 多用户与账号

## 2. 用户路径

> 左侧「研究历史」→ 卡片里直接查看报告 / 继续研究 / 追问
> → 「知识库」→ 左列点文档 → 右侧读分块全文
> → 搜索命中项也可点开对应文档

## 3. 相对基线的增量

- 后端：`KnowledgeBase.get_document()`、`GET /api/kb/{doc_id}`、历史列表补充字数/追问数。
- 前端：`view-history` 页面、KB `kb-layout` 分栏、`loadKbDoc()`、历史卡片动作。

## 5. 本版风险与待办

- **知识库只读**：暂不支持上传/编辑文档，标签与分类也没有数据层。
- **字数统计**：用 `report.md` 字符数，包含 Markdown 符号，不是严格中文字数。
- **继续研究入口**：用 `prompt()` 收集问题，交互较原始；后续可换成表单弹窗。
- **移动端**：KB 分栏在窄屏隐藏右侧详情，需后续做抽屉。
