# MVP-1.6 · 文档上传与自动分类

> 基线：PROJECT.md v1.15
> 前置版本：MVP-1.5（历史页与知识库分栏）
> 日期：2026-10-21
> 状态：**已完成**（117 个离线单测；md 与 pdf 均实测上传）

## 1. 本版范围

**包含什么**：

1. **添加文档**：知识库支持上传 `.md` / `.markdown` / `.txt` / `.pdf`（≤ 20 MB）。
2. **自动分类**：本地关键词规则，标题命中权重 3、正文 1，取前 3 个标签，主分类为最高分标签。
3. **分类筛选**：知识库顶部「全部分类」下拉，按主分类过滤。
4. **标签展示**：列表与详情显示主分类和标签；文档类型显示为「研究沉淀 / 笔记 / PDF」。
5. **旧库迁移**：自动补 `kind / category / tags` 字段；旧文档在读列表时按内容回填标签。
6. **接口**：`POST /api/kb/upload`（multipart），`GET /api/kb/{id}` 返回标签与分块。

**不包含什么**：

- 扫描版 PDF 的 OCR（只提取可复制文本）
- 手动编辑标签/分类
- 文档正文编辑
- 上传网页 URL 抓取（后续可加）

## 2. 用户路径

> 知识库 →「＋ 添加文档」→ 选一个 md/txt/pdf
> → 自动分类与打标签 → 左列显示类型/分类/标签
> → 点文档，右侧读分块全文
> → 用「全部分类」筛选

## 3. 分类规则

| 分类 | 触发词示例 |
|---|---|
| RAG | rag、检索增强、embedding、重排、召回 |
| Agent | agent、智能体、MCP、function calling |
| LLM 应用 | llm、大模型、prompt、推理、微调 |
| 向量数据库 | 向量数据库、faiss、milvus、qdrant、hnsw |
| 网络编程 | socket、epoll、tcp、grpc |
| 系统设计 | 架构、高并发、分布式、缓存、消息队列 |
| 性能优化 | 延迟、吞吐、benchmark、qps、p99 |
| 安全与合规 | 安全、注入、漏洞、合规、隐私 |
| 数据处理 | etl、pandas、sql、数据仓库 |
| 产品与商业 | 产品、市场、定价、竞品 |

无命中时归为「其他 / 未分类」。

## 5. 本版风险与待办

- **规则分类较粗**：只做关键词命中，不理解语义；后续可选用 embedding 聚类或 LLM 打标（会消耗额度）。
- **扫描 PDF**：无文本层，会提示需要 OCR。
- **标签不可编辑**：自动结果不理想时目前只能重新上传或等后续加编辑。
- **去重**：按正文 SHA-256 去重，同一文件改名上传不会重复入库。
- **分类体系固定**：新增领域需要改 `dra/classify.py` 的规则表。
