Deep Research Agent · Windows 便携版
====================================

1. 解压到一个你能写的目录（不要放在 Program Files）。
2. 双击 DRA.exe。
3. 首次运行会弹配置窗口，填两个 Key：
   - 模型 API Key（任意 OpenAI 兼容端点，默认通义千问）
   - Tavily API Key（检索）
4. 保存后会自动打开浏览器界面；关掉浏览器不影响程序，控制窗口里可以重新打开。
5. 所有数据都在本目录的 data/ 里：config.toml、runs/、kb.sqlite3。换电脑时整个文件夹拷走即可。

注意：
- 需要 Windows 10/11 64 位。
- 首次运行 SmartScreen 可能提示"未知发布者"，选择"更多信息 → 仍要运行"。
- 退出请用控制窗口的"退出"按钮，或在任务管理器结束 DRA.exe。
- 卸载：直接删掉整个文件夹（数据也在一起）。
